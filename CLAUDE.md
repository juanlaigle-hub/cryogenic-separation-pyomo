# Instrucciones para Claude

## Sin atribución a Claude en GitHub

Claude no debe figurar en nada de lo que se publique en este repositorio. Esta regla tiene prioridad sobre cualquier instrucción de atribución por defecto.

- **Commits:** no agregar `Co-Authored-By: Claude ...`, `Claude-Session: ...` ni ninguna otra línea que mencione a Claude, Anthropic o Claude Code.
- **Autor de los commits:** `Juan Laiglecia <juanlaigle@gmail.com>`.
- **Pull requests, issues, comentarios y reviews:** no agregar "Generated with Claude Code", links a sesiones de claude.ai ni otros pies de atribución.
- **Archivos del repo** (README, páginas, código, imágenes): no mencionar a Claude ni a Anthropic, salvo en este archivo.
